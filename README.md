# Study of Model Robustness under Different Chest X-ray Datasets

## Overview

This project studies the robustness of deep learning models when tested on different chest X-ray datasets. The objective is to evaluate how well models maintain their performance when the data distribution changes.

The study compares multiple deep learning models across different datasets and analyzes their performance using various evaluation metrics.

---

## Objectives

- Study the performance of deep learning models on different chest X-ray datasets.
- Reproduce experiments from published research papers.
- Evaluate model robustness when testing with different datasets.
- Compare model performance and stability across different conditions.

---

## Datasets

The experiments use three chest X-ray datasets:

- COVID-19 Radiography Dataset
- RSNA Pneumonia Detection Challenge
- Tuberculosis (TB) Chest X-ray Database

Each dataset contains different image characteristics and data distributions, allowing evaluation of model performance under different environments.

---

## Methodology

The experiment workflow consists of:

1. Reviewing related research papers and selecting reference models.
2. Reproducing experiments based on published settings.
3. Preparing datasets and applying preprocessing methods.
4. Training deep learning models with suitable hyperparameters.
5. Evaluating model performance across different datasets.
6. Analyzing model robustness and stability.

---

## Model Training

The models are trained using:

- Deep learning architectures from previous research.
- Hyperparameter tuning to improve model performance.
- 5-fold Cross Validation to evaluate model stability.

---

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- AUC (Area Under the Curve)
- ROC Curve
